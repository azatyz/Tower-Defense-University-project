# Tower-Defense-University-project

Игра на **Python + Pygame** для университетского проекта: Tower Defense с волнами врагов, экономикой и разными типами башен.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Управление

- `1` — выбрать Basic Tower
- `2` — выбрать Sniper Tower
- `3` — выбрать Fast Tower
- `4` — выбрать Bomb Tower с уроном по области
- ЛКМ — построить выбранную башню (вне дороги)
- ЛКМ по построенной башне — выбрать башню
- `U` или кнопка `Upgrade` — улучшить выбранную башню за деньги
- `Esc` — пауза / продолжить игру
- В паузе доступны кнопки `Resume`, `Restart`, `Quit`
- `E` — следующая волна
- `R` — рестарт после Game Over
- `Q` — выход после Game Over

> Примечание: спавн тестового врага по `Пробелу` временно отключен.

## Структура проекта

- `main.py` — главный игровой цикл, класс `Game`
- `entities.py` — враги, башни, снаряды, утилиты
- `game_manager.py` — состояние игры: волны, деньги, HP
- `path.py` — путь врагов и проверка постройки
- `ui.py` — визуальные подсказки и превью строительства
- `settings.py` — константы и цвета
- `tests/` — unit-тесты базовой игровой логики
- `requirements.txt` — зависимости

## Что важно для защиты

- ООП: есть абстрактный `GameObject`, наследование врагов и башен, отдельные классы для UI, пути, апгрейдов и менеджера игры.
- SOLID/архитектура: выбор цели вынесен в стратегии `TargetStrategy`, поэтому башни можно расширять без переписывания игрового цикла.
- Алгоритмы: проверка расстояния до отрезка пути, выбор цели по стратегии, прогресс врага по маршруту, урон по области с затуханием, расчет стоимости апгрейда.
- UX: предпросмотр башни, подсветка доступности строительства, выбор башни, панель апгрейда, панель волн, меню паузы, сообщения HUD.
- Тесты: базовую игровую логику можно проверить командой `python -m unittest discover -s tests`.
