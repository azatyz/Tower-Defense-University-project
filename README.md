# Tower Defense (Python + Pygame)

Игра в жанре Tower Defense с волнами врагов, экономикой, прокачкой башен, сохранением рекорда и раздельной архитектурой `models / controller / view`.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

После запуска открывается главное меню, затем начинается игровая сессия.

## Управление

- `1`, `2`, `3`, `4` - выбор типа башни: `Basic`, `Sniper`, `Fast`, `Bomb`
- `ЛКМ` по пустому месту - построить выбранную башню
- `ЛКМ` по башне - выбрать ее и открыть панель информации
- `ПКМ` - снять выбор строительства и сбросить текущее выделение
- `U` - улучшить урон выбранной башни
- `F` - улучшить радар выбранной башни
- `S` - продать выбранную башню
- `E` - сразу запустить следующую волну
- `T` - включить или выключить отображение радиусов в любой момент
- `Esc` - открыть или закрыть меню паузы
- `R` и `Q` - рестарт и выход доступны только в меню паузы

Если база уничтожена, на экране поражения можно нажать `Esc`, открыть паузу и уже там выбрать рестарт или выход.

## Что реализовано

- 4 типа башен с разными характеристиками и стратегиями атаки
- обычные, быстрые, тяжелые враги и босс юбилейной волны
- динамическая генерация состава волны по бюджету
- раздельная прокачка урона и радара
- система липкой цели
- упреждающее наведение снарядов
- AoE-урон с затуханием по расстоянию
- пауза, стартовое меню, HUD, сообщения и звуки
- сохранение рекорда при поражении и при выходе из сессии

## Архитектура и ООП

Проект разделен на несколько слоев:

- `models` - игровые сущности, путь врагов и менеджер состояния партии
- `controller` - игровой цикл, обработка ввода и правила игры
- `view` - отрисовка, интерфейс и звук
- `config` - настройки и сохранение рекорда

В коде используются основные принципы ООП:

1. Инкапсуляция: логика движения, построения, волн, экономики и попаданий скрыта внутри классов и отдельных модулей.
2. Наследование: `Enemy`, `Tower` и `Projectile` наследуются от базового `GameObject`, а конкретные типы башен и врагов расширяют общее поведение.
3. Полиморфизм: `GameRenderer` делегирует отрисовку объектам через единый метод `draw(screen)`, а сами объекты рисуют себя по-разному.
4. Абстракция: `SoundManager` скрывает детали работы `pygame.mixer`, а `GameManager` инкапсулирует игровое состояние.

Дополнительно используется паттерн `Strategy` для выбора цели:

- `NearestTargetStrategy` - ближайший враг
- `StrongestTargetStrategy` - враг с наибольшим HP
- `FirstInPathTargetStrategy` - враг, прошедший дальше всех по маршруту

## Тесты

Проверить базовую логику можно командой:

```bash
python -m unittest discover -s tests
```

Тесты покрывают размещение башен, выбор цели, улучшения, сохранение рекорда, часть логики волн и урон базе.
