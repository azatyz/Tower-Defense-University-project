# 🏰 Tower Defense (Python + Pygame)

Классическая игра в жанре Tower Defense с волнами врагов, экономикой и прокачкой. 

## 🚀 Как запустить

Убедитесь, что у вас установлен Python. Установите зависимости и запустите главный файл:

```bash
pip install -r requirements.txt
python main.py
```

## 🎮 Управление и геймплей

Интерфейс спроектирован так, чтобы в игру можно было играть как мышкой, так и с клавиатуры (для скорости):

* **[1], [2], [3], [4]** — выбор типа башни (Basic, Sniper, Fast, Bomb).
* **ЛКМ (Клик левой кнопкой мыши)**:
  * По пустому месту — построить выбранную башню.
  * По уже построенной башне — открыть панель информации и прокачки.
* **ПКМ (Правая кнопка мыши)** — отменить выбор башни для постройки.
* **[U]** — прокачать урон у выбранной башни.
* **[F]** — прокачать радар (радиус) у выбранной башни.
* **[S]** — продать выбранную башню (возвращает 50% стоимости).
* **[E]** — досрочно запустить следующую волну врагов.
* **[T]** — включить/выключить отображение радиуса атаки.
* **[Esc]** — пауза (в меню паузы доступны продолжение, рестарт и выход).

## 🧠 Что под капотом (Архитектура и ООП)

Проект построен не на глобальных переменных, а на модульной архитектуре. Код легко читать и масштабировать благодаря 4 столпам ООП:

1. **Инкапсуляция**: Вся сложная математика (например, высчет дистанции до отрезков пути в `path.py`) или работа с состоянием игры (волны, экономика в `game_manager.py`) скрыта внутри классов. Главный цикл не лезет в формулы, а просто вызывает удобные методы.
2. **Наследование**: Абстрактный класс `GameObject` задает базовый контракт. Вся тяжелая логика кулдаунов и поиска целей прописана в базовом классе `Tower`, а конкретные башни (`BombTower`, `SniperTower`) просто наследуют ее, меняя лишь характеристики.
3. **Полиморфизм**: В главном цикле (Game Loop) рендер работает через единый интерфейс. Метод `draw()` вызывается одинаково для башен, врагов и интерфейса, но каждый объект отрисовывает себя по-своему.
4. **Абстракция**: Аудиосистема (`SoundManager`) абстрагирует логику библиотеки `pygame.mixer`. Игровой цикл просто передает команду `play("click")`, не задумываясь об обработке ошибок или поиске `.wav` файлов на диске.

Также внедрен паттерн **Strategy** (`TargetStrategy` в `entities.py`), который позволяет башням выбирать цель по разным алгоритмам (ближайший, самый сильный, самый быстрый), не переписывая ядро башни.

## 🧪 Тестирование

Критически важная логика покрыта юнит-тестами. Проверить работу алгоритмов поиска цели и валидацию постройки можно командой:

```bash
python -m unittest discover -s tests
```
